# 日本語の AI slop をなくす

書いた後に走らせる。文体 (だ・である / です・ます) と事実は変えない。

- 日英混在の文書は、日本語の部分にだけ当てる。英語は [reference-en.md](reference-en.md) に従う
- コード内コメントは、残すと決まったものの文言だけ直す。消すか残すかは判定しない (本スキルの対象外)

1. 「落とすもの」と「感じ方ではなく動きを書く」で走査して書き直す
2. 最後に自己監査する。「これを AI 生成だと分からせているものは何か」。残りを潰して 1 周で終える

## 落とすもの

置き換え方が書いてなければ消す。

**語彙。** 不可欠な / 極めて重要な / 非常に / まさに / 〜に他ならない / 〜と言っても過言ではない / 紐解く / 深掘りする / 革新的 / 画期的 / シームレス。平語に置き換えるか消す。「重要なのは」「注目すべきは」「鍵を握るのは」「本質は〜にある」の前置き用法、文頭の「さらに」「また」「加えて」の連発も同じ。「大幅に」「著しく」は数字に置き換える。

**カタカナの飾り。** パラダイム / シナジー / レバレッジ / ソリューション。実体を指すなら残し (npm エコシステム)、飾りなら平語に。

**気取り (Mannered prose)。** 平叙で言えるところの警句、効果狙いの断片、コードの人格化、比喩の動詞。「繋ぐか消すか」「そう、テストだ。」は消す。「〜は諸刃の剣だ」は「〜には副作用がある」。「効かせる舵」は「変える価値のあるパラメータ」。「型が守ってくれる」は「型が合わないとビルドが落ちる」。「〜に相乗りする」は「〜をそのまま使う」。「〜の上に立つ」は「〜に依存する」。言いたいことをそのまま書く。

**前置き。** 「本稿では〜について説明します」「以下では〜を見ていきます」。見出しと本文で足りる。

**出典のない主張。** 「専門家によれば」「〜とされています」「〜と言われています」「〜が求められています」「今後の発展が期待されます」。出典か具体的な事実を書く。書けないなら消す。

**中身のない述部。** 「〜を実現し」「〜を可能にし」「〜を浮き彫りにしています」「〜を反映し」「〜に効きます」。実際に何が起きるのかに置き換える。

**冗長。** 「〜を行う」は「〜する」。「〜することが可能です」は「〜できる」。「〜という点において」は「〜で」。「〜としての役割を果たす」「〜に位置づけられる」は「〜だ」。「〜という形になります」「〜となっております」は丸ごと消す。

**長文。** 読み返さないと構造が取れない文は 2 つに割る。1 文 1 事。「〜ですが、〜であり、〜のため」と接続助詞で繋ぎ続けない。

**圧縮しすぎ。** 助詞を落とした漢語の羅列 (「設定変更後再起動必須」)、体言止めの連続、矢印や記号での代用 (「不正な日付 → exit 2、書き込みなし」)、断りのない略語。読み手が解読する側に回る。「設定を変えたら再起動する」「パーサは不正な日付を拒否し、終了コード 2 で終わる。ファイルは書かない」と、助詞と動詞のある文にする。矢印と略語は言葉に開く。

**ヘッジ。** 「〜と考えられます」「〜のように思われます」「基本的に」「一般的に」。積み重なったら 1 つに潰す。

**動作主の消えた受動。** 「検証が行われます」は「コンパイラが検証する」。誰がやるのかを名指しする。ただし動作主が不明か、どうでもよいなら受動のまま (「〜と呼ばれる」)。

**対話の残骸。** 「いかがでしたか」「〜していきましょう」「ご参考になれば幸いです」「素晴らしいご質問です」。

**構造の癖。**

- 無理に 3 つへ揃えない。実際の個数で書く
- 同じものを言い換え続けない。1 つ選んで繰り返す
- 「〜だけでなく〜も」「単なる〜ではなく〜」で持ち上げない。言いたい方を直接書く
- 「A から B まで」で A と B が同じ尺度に乗っていないもの (「型安全からチームの士気まで」) は並べて書く。並ぶものが同種なら残す
- 太字ラベルが直後の文と同じことを言っているもの (`**注意点:** 注意点として…`) は散文に直す。ラベルの後に新しい情報が続くなら残す
- 太字と絵文字を飾りに使わない。固有名詞や略語をいちいち太字にしない
- 文中ダッシュ「——」は使わず句点で切る。括弧は語の補足だけに使い、中が文になるなら外に出す

## 感じ方ではなく動きを書く

判断は根拠とセットなら残す。根拠のない印象語だけを消す。「設計が綺麗だ」は何がどう綺麗かが続くなら判断で、続かないなら印象。

仕組みか数字を書く。「設定が手近にある」ではなく「`setup.sh --list` が対象一覧を出す」。読み手に何をさせるか・何を知らせるかを問い、具体的な指示・事実・数字として言い直す。言い直せないなら消す。

その文が別のプロジェクトの文書にそのまま載るなら、目の前の対象について何も言っていない。消す。
